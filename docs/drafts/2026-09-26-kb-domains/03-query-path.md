# Путь запроса: хэш, алиасы глоссария, Jev, обучаемые алиасы

## Проблема

- Сейчас: вопрос с ID нормы → прямой поиск по якорям; иначе кэш по хэшу нормализованного вопроса; иначе Jev по всем
  units домена (+ BM25, линейное слияние Jev + 0,3 · BM25/max). Порог «ответа нет» — максимум Jev < 0,6
  (предварительно: пустышки 0,04–0,53, одна 0,83; вопросы с ответом — от 0,75).
- Хэш помогает только на точном повторе: живых вызовов 16, повторов 3 (19 %) — данных мало; у координатора с
  типовыми вопросами пакета повторов может быть больше.
- «BM25 первым» отклонено (README): уверенность BM25 не отличает верный ответ от неверного.
- Термины вопроса и документа расходятся (перефраз, английский вопрос к русским документам) — это и лечит Jev.

## Идея

Предложение maintainer'а (2026-09-26):

1. Вопрос → нормализация → **хэш**: повтор — ответ из кэша.
2. Нет в кэше → **поиск по алиасам глоссария с фильтром домена**: ключевые слова вопроса → термины → units, которые
   используют термин (`uses-term`) или несут алиас. Детерминированно, без Jev.
3. Нет совпадения → **Jev**; LLM агента выбирает нужные units из выдачи.
4. **Обучение:** ключевые слова вопроса сохраняются алиасами выбранных units — следующий такой вопрос пойдёт по п. 2.
5. **Риск:** LLM может выбрать неверно — неверный алиас закрепит ошибку и будет уводить следующие вопросы мимо Jev.

## Вопросы для grilling

1. Нужен ли хэш? Рекомендация: оставить — он бесплатен и уже есть (это кэш оценок Jev); польза — у координатора с
   типовыми вопросами; через месяц посмотреть долю повторов в `usage.jsonl`.
2. Алиас глоссария — замена Jev или подсказка? Рекомендация: **подсказка** (буст / предфильтр кандидатов), Jev всё
   равно оценивает: термин «waiver» есть в 20+ units, совпадение термина не выбирает норму.
3. Обучаемые алиасы: как не закрепить ошибку LLM? Рекомендация: алиас — **кандидат** с происхождением (вопрос, дата,
   агент, unit); в силу — после ≥ 2 независимых подтверждений (`--used` из разных сессий или человек); отдельно от
   курируемых алиасов; снимается при изменении источника unit; журнал для ревью.
4. Откуда подтверждение «выбрал правильно»? Рекомендация: `--used` после ответа + отсутствие исправления в той же
   сессии; ревью отчёта «Нормы» координатором (04-agent-workflow).
5. Как проверить путь по алиасам на стенде без утечки? Рекомендация: алиасы учатся только на живых вызовах
   (`via: cli|ui`), никогда на вопросах стенда; контроль — новый набор, отдельная метрика «ответ по алиасу верен».
6. Порог «ответа нет» 0,6 — подтвердить на следующем контроле (≥ 10 пустышек)? Рекомендация: да, до этого —
   предупреждение, не отказ.
7. Внутри домена гибрид или только Jev? dH − dJ не доказано ни на одном наборе. Рекомендация: оставить гибрид (BM25
   бесплатен, помогает на терминах), пересмотреть по следующему контролю.

## Вне объёма

- Эмбеддинги и векторные базы — не сравнивались; Jev + BM25 закрывают потребность на текущем корпусе.
