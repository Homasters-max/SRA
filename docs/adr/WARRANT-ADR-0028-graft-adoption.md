## Context

Эксперимент [ADR-0026](WARRANT-ADR-0026-graft-experiment.md) / [ADR-0027](WARRANT-ADR-0027-graft-tuning.md) —
отчёт [docs/process/graft-report.md](../process/graft-report.md):

- **Бенчмарк (8 вопросов, пары `[A]`/`[B]`) — `accept`:** медиана отношения прочитанных при исследовании байт 0,54
  (порог ≤ 0,8), токены −22 %, вызовы −29 %, recall и precision 1,0 у обеих меток; отступлений от алгоритма — 0;
  `cs` в `[B]` — 0.
- **Поле (`test-levels`, 6 групп)** согласуется по направлению (прочитанное −51 %, до первой правки −41 %), но
  смешано по объёму групп; неверных ответов графа, приведших к ошибке, — 0.
- **Риски:** потолок бенчмарка (вопросы оказались по силам обеим меткам — recall их не различает); ложные рёбра графа
  по совпадению имён (q8: локальная переменная `forward` связана с функцией `forward`) — агент отсеял их по правилу 3;
  Graft pre-1.0.

## Decision

1. **Принять.** Поиск по коду через `scripts/dev/cs.js` — стандарт для субагентов групп задач разработки WARRANT.
   Чередование `[A]`/`[B]`, метки и зонд прекращаются; эксперимент закрыт (`docs/process/graft.md` —
   `status: closed`).
2. **Ограничения ADR-0026 п. 2–3 остаются:** только CLI через обёртку; `graft init` / `upgrade` / `mcp` / `brain`,
   хуки, MCP, statusline не используются; версия зафиксирована (`GRAFT_VERSION` в `cs.js`, сейчас 0.19.0); индекс
   вне git.
3. **Алгоритм — навык `.claude/skills/code-search/SKILL.md`, вызываемый моделью** (описание: поиск по коду
   `packages/**`, `scripts/**`). Слепота больше не нужна; навык доступен и основной сессии. В промпт субагента —
   одна строка-ссылка ([coordinator.md](../process/coordinator.md) §2). `docs/process/code-search.md` удалён.
   Правило 3 навыка дополнено: место из `callers`, которое не сходится, проверяется `cs grep` и диапазоном кода
   (ложные рёбра по имени).
4. **Обновление Graft — только через регрессию бенчмарка:** 8 субагентов `[A]` на новой версии против записанных
   `[B]`; `accept` (отношение ≤ 0,8, recall не ниже) — версия принимается, иначе остаётся прежняя
   ([graft.md](../process/graft.md) §6).
5. **Наблюдение в поле:** после каждой группы `graft-metrics.js run --mode on` (`/group-stats`); `misled` — условие
   пересмотра этого ADR.
6. **Усиление бенчмарка — later.** Вопросы, где граф или grep ошибаются (одноимённые символы, переименованные импорты,
   re-export). Триггер: первый `misled` в поле или обновление Graft.

## Consequences

- `coordinator.md`: без меток и зонда; строка про навык в общем промпте; запись группы — `--mode on`.
- `graft-metrics.js run` принимает `--mode on` для записи без метки; `/stats-report` удалена (эксперимент закрыт),
  `/group-stats` — наблюдение.
- Временные worktree `SRA-bench-*` удаляются; `scripts/dev/bench*`, `graft-metrics*`, `cs.js`, данные
  `graft-lab/` (вне git) остаются — бенчмарк нужен для регрессии (п. 4).
- [13 §3](../13-roadmap.md): later-идея «Graft в продукте» — первая половина триггера (accept) выполнена, вторая
  (Graft ≥ 1.0) — нет.

## Alternatives

- **Отклонить** — нет оснований: порог пройден с запасом, вреда в поле нет.
- **Продолжить эксперимент на фазе 4** — дорого и мало что добавит, пока бенчмарк не усилен (п. 6).
- **Оставить алгоритм текстом в промпте** — работает, но основная сессия его не видит, а слепота больше не нужна.
- **Обновлять Graft свободно** — отвергнуто: pre-1.0, ломающие изменения в 0.6 / 0.7 / 0.9 / 0.17.
