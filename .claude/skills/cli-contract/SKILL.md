# Линза: контракт CLI

Команда CLI — API: её читают агенты, CI и `warrant ci` фабрики SEF, а не только человек. Источник — агент developer-tooling-engineer каталога agency-agents, адаптирован к WARRANT ([ADR-0033](../../../docs/adr/WARRANT-ADR-0033-git-process.md) п. 8). Норма — [04 §7](../../../docs/04-lifecycle.md) и ADR; линза только задаёт вопросы, ответы ложатся в spec или design Change.

## Вход

- Команда (новая или меняющаяся) и её место: delta spec, design.md Change, `packages/cli/src/commands/<команда>.ts`.
- Действующее: конверт `{ command, ok, change, data, errors }` (04 §7), `EXIT` = 0 OK / 1 FAIL / 2 WAIT / 3 CONFIG (`src/core/errors.ts`), `WarrantError(code, message, { path, exitCode })`.

## Шаги

Вопросы по порядку; каждый «нет» — пункт в spec (REQ/SCN) или строка `I-N`, а не молчаливое «потом»:

1. **Ошибка называет исправление.** Для каждого кода ошибки команды: что сделать пользователю или агенту — команда, флаг, файл? Сообщение без следующего шага — дефект. Поле подсказки у `WarrantError` — вопрос фазы 4 (`docs/handoff/phase-4.md`).
2. **Exit-коды — API.** Каждый исход команды — ровно один из 0/1/2/3; `WAIT` (2) — не ошибка; конфигурация и вход — 3. Есть ли сценарий SCN на каждый код?
3. **JSON стабилен.** Поля `data` названы и типизированы в spec; добавление поля — совместимо, переименование и удаление — несовместимо (версия CLI, R-14). Вывод под golden или app-тестом с точным `toEqual`?
4. **Меняющие состояние — `--dry-run`.** Команда пишет record, evidence, waivers, lock, файлы OpenSpec? Тогда: что покажет `--dry-run` (план без записи) и совпадает ли он с настоящим прогоном (тест пары)?
5. **Повтор безопасен.** Второй вызов с тем же входом — тот же результат или явная ошибка «уже сделано», не порча состояния (идемпотентность, частичная запись при сбое).
6. **`--help` с примером.** Описание команды и каждого флага, хотя бы один пример вызова; флаги, требующие человека (`--by`, `--activate`), так и помечены.
7. **Не-TTY.** Без TTY — JSON по умолчанию (04 §7), без интерактивных вопросов и цвета; всё, что нужно агенту, — в аргументах.

## Стоп

- Ответ требует изменить 04 §7 или принятый ADR — не решать линзой: вопрос maintainer'у, норма — новым ADR.
- Команда вне фазы (`guard`, `ci`, `run`, `analyze` до фазы 4) — только вопросы в spec, не реализация.

## Отчёт

Таблица «вопрос → ответ spec/design или пробел»; пробелы — предложенные REQ/SCN или строки `I-N`.
