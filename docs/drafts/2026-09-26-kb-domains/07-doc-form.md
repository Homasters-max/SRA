# Форма документов для поиска (заголовки, описания)

## Проблема

- Jev видит заголовок и первый абзац документа. У ADR это история (`## Context`, «Уточнено ADR-…»), у `kernel/spec` —
  первое требование про JSON Schema; поэтому поиск по документам целиком промахивается (2026-09-26).
- Справочник `D:\kb` (карточки ~60 строк, `description` под вопрос, `aliases` RU/EN): Jev MRR 0,57 против 0,32 на SRA.
- Домены решают это без правки документов (units с собственными `title` / `summary`).

## Идея

- Информативные заголовки разделов («Сколько PR на одно изменение», не «Decision» / «п. 3»), суть нормы — первой
  фразой раздела, одна норма на раздел, EN-термины рядом с RU.
- `description` и `aliases` во frontmatter ADR и docs.

## Вопросы для grilling

1. Нужно ли это при доменах? Рекомендация: не сейчас — домены дали 100 % в топ-3 без правки документов; вернуться, если
   нарезка станет дорогой или units разойдутся с документами.
2. Если да — форма в ADR-0032 и проверка `dev-context.test.ts`? Рекомендация: да, правило «о форме — проверкой».
3. Принятые ADR — править тело ради поиска? Рекомендация: нет; только frontmatter.

## Вне объёма

- Архив Changes — неизменен (ADR-0021).
