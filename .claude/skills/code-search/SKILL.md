# Поиск по коду через граф

Порядок принят [ADR-0028](../../../docs/adr/WARRANT-ADR-0028-graft-adoption.md), уточнён
[ADR-0029](../../../docs/adr/WARRANT-ADR-0029-graft-audit-dev-hooks.md); команды, сценарии и слепые зоны графа —
[reference.md](reference.md). Шаги 1–6 обязательны: у субагента вызов, нарушающий шаги 1, 2 или 5, хук отклоняет до
выполнения ([ADR-0031](../../../docs/adr/WARRANT-ADR-0031-pretooluse-deny.md)) — сделай то, что говорит отказ.

## Вход

- Вопрос о коде WARRANT: `.ts`/`.js` под `packages/`, `scripts/` рабочего дерева (любого worktree репозитория).
  Инструмент — `cs`: `node scripts/dev/cs.js <команда>` из корня worktree.
- Не индексируются и ищутся обычными средствами (grep, Read) без ограничений: документы (`docs/**`, `openspec/**`,
  `*.md`), данные и конфиги (`*.json`, `*.yaml`, `package.json`), `node_modules`, `.ts`/`.js` вне `packages/`,
  `scripts/` (scratchpad, temp, другие репозитории).

## Шаги

1. **Код ищешь только через `cs`.** Не для кода: инструмент Grep по `packages/`, `scripts/`, `*.ts` (и Grep без пути);
   `grep -r`, `rg`, `git grep`, `Select-String`; `graft` напрямую. Список файлов (`ls`, `find -name`, Glob) — можно.
   Место неизвестно — `cs ask "<поведение>" --source`; имя или литерал — `cs grep "<шаблон>"`.
2. **Код читаешь только диапазонами.** Сначала `cs skeleton <файл>` (или `file:line` из ответа `cs`), затем Read с
   `offset`/`limit` (`sed -n a,bp`) — нужные строки. Диапазон на весь файл (`sed -n 1,Np`, `head -N`) — чтение
   целиком; целиком можно только файлы до 40 строк. `skeleton` ответил «no definitions indexed» —
   `cs grep "^(export )?(const|let)" --in <файл>`, затем диапазон.
3. **Перед изменением сигнатуры, переименованием, удалением, сменой поведения экспорта — `cs impact <символ>`.**
   Это список правок: каждое место учесть или явно отметить, почему не затронуто. `[graph]` (ребро без строки
   вызова) и `local?` (одноимённая переменная) — проверь диапазоном. `cs callers <символ> -d 2` — для цепочек, не
   как список правок.
4. **Один вызов — один ответ.** Команду выбирай по таблице reference.md и действуй по ответу; не переспрашивай
   другими словами. `ask` лексический: ответ `(empty)` или `(lexical)` без слов вопроса — «такого нет»: проверь
   одним `cs grep` и действуй.
5. **Не обрезай вывод `cs`** (`| head`, `| tail`): он уже ограничен и сообщает, что отброшено. Для разбора
   программой — `--json`.
6. **Код выхода `cs`:** 1 — graft не нашёл (нет символа, пустой `--in`, неверный regex); 2 — поправь команду по
   тексту ошибки; 3 — остановись (Стоп).

## Стоп

- `cs` вернул код 3 — остановиться и сообщить; не обходить другим инструментом.
- Пусто после двух разных команд `cs` по одному вопросу (`grep` с ослабленным шаблоном и `ask`) — тогда обычный
  поиск по этому вопросу, с пометкой в отчёте.
- Отказ хука мешает законной работе — не обходить скриптом: записать в отчёт и сказать координатору.

## Отчёт

Субагент — раздел «Поиск по коду» отчёта группы ([coordinator.md](../../../docs/process/coordinator.md) §2): 2–3
примера, как находил нужные места; где `cs` ошибся или промолчал и к чему это привело (или «нет»); отказы хука,
мешавшие работе (или «нет»).
