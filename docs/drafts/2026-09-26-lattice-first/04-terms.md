# Термины модели: один список для kb-domains и lattice-first

## Проблема

- За раунды grilling 2026-09-26 одни и те же вещи назывались по-разному: «snapshot» — то пул Jev (Q20), то ответ
  (Q30), то состояние группы (Q47); «домен» — то context LATTICE (черновик 02), то projection (Q7); «unit» — то член
  группы, то карточка для Jev. Без единого списка черновики расходятся.
- Термины должны совпадать с LATTICE (`lattice/docs/01-object-substrate.md`, `03-substrate-decisions.md`), Anchor
  Modeling (AM) и DWH там, где понятие одно и то же, и явно отличаться там, где понятия разные.

## Идея

Единственный список терминов потоков kb-domains и lattice-first. Остальные файлы ссылаются сюда и не вводят синонимов.
Колонка «LATTICE» — ближайшее понятие substrate; «AM» — Anchor Modeling / Transitional Modeling; «DWH» — Kimball.
Прочерк — аналога нет.

### Слова, которые больше не используются

| Было | Стало | Почему |
|---|---|---|
| «snapshot = оценённые объекты» (Q20) | пул (T35) | snapshot — состояние группы (Q47) |
| «snapshot → вопрос» | mapping «вопрос → группа» (T36) | калибровка не должна ломать mapping (Q47) |
| «домен = context» (черновик 02) | домен (T7) | context — граница языка, домен — работы (Q7) |
| «use», `--used` | вердикт (T39) | вердикт несёт диагноз (Q37) |
| статусы `inferred` / `observed` / `declared` / `contested` одной осью | две оси доверия (T42) | так в LATTICE: основание и спор — разные вопросы (§1.1) |
| `posits.jsonl` (Q55) | ledger (T14) | имя механизма; `journal` занят в `runtime` |
| `content_hash` в членах (черновик 09) | версия (T19) | Q21′ |

## Вопросы для grilling

1. Имена ledger (T14) и группа (T21) — утвердить? Рекомендация: да. Альтернативы: `claims` (слишком общее),
   `journal` (занят типом `runtime/journal`), `set` / `collection` (путаются с типами данных).
2. Составная группа: отдельного типа ядра не заводить — это группа, члены которой группы (T23)? Рекомендация: да,
   допустимость вложения — в типе реестра (Q44).

## Вне объёма

- Термины WARRANT (`docs/02-vocabulary.md`) не меняются; при записи ADR термины этого списка, нужные WARRANT,
  добавляются туда отдельным решением.
- Термины LATTICE не переопределяются: при расхождении — вопрос в grilling реестра LD-*.
