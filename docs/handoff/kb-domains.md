# kb-domains

## Цель

Поиск по документации для агентов WARRANT через домены: документы нарезаны на units (одна норма — ссылки на документ,
код, тесты), агент ищет в своём домене. Пилот `lifecycle` и `kernel` принят на контроле 2026-09-26c. Дальше — grilling
черновиков [2026-09-26-kb-domains](../drafts/2026-09-26-kb-domains/README.md): модульная архитектура поиска (08),
записи оценок и снимки (09), где живут домены (01), модель сущностей на контракте LATTICE (02), путь запроса (03),
работа агентов (04), 37 противоречий (05), стенд (06), форма документов (07). Итог — ADR и реализация. Раунды 1–2
(2026-09-26): 08 решён (файл 10), LATTICE — отдельный проект после фазы 4 (`2026-09-26-lattice-first`); 02–07 — после
его vertical slice.
