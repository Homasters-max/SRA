# code-search — справочник

Команды и сценарии к навыку [code-search](SKILL.md). `cs` = `node scripts/dev/cs.js` из корня worktree (из подкаталога —
`node "$(git rev-parse --show-toplevel)/scripts/dev/cs.js"`; `--in` и путь файла — от текущего каталога). Индекс
строится и обновляется сам. `--json` — у всех команд, кроме `version`.

## Чего граф не видит

Аудит против компилятора TypeScript ([ADR-0029](../../../docs/adr/WARRANT-ADR-0029-graft-audit-dev-hooks.md),
[отчёт](../../../docs/process/graft-audit.md)): вызовов через порты и интерфейсы (`ctx.git.head()`, `ctx.checks.run()`);
вызовов из другого файла, если имя определено в нескольких файлах; вызовов методов у переменной без известного типа и
в цепочках (`project().withChange()`). Константы модуля — не узлы. Поэтому `callers` — нижняя граница, а список правок
даёт `impact`.

## Команды

| Задача | Команда |
|---|---|
| Что обновить, если меняю X | `cs impact <символ>` (`Type.method` — только вызовы метода; `--in <путь>`). Константа, тип, метод интерфейса — не функция графа: `impact` ищет каждое вхождение имени (`match: word`) |
| Где поведение X (место неизвестно) | `cs ask "<где X>" --source` (`--in <путь>`, `-n N`) |
| Все вхождения символа или литерала | `cs grep "<шаблон>"` — JS-regex: «или» пиши `a|b` (не `a\|b`), `(` экранируй; литерал — `--fixed`; `-i`; `--in <путь>`. Не нашёл — ослабь шаблон (голое имя) |
| API файла | `cs skeleton <файл>` — функции, типы, методы со строками; константы — `cs grep "export const" --in <файл>` |
| Кто вызывает / цепочка | `cs callers <символ> -d 2`; от чего зависит — `--direction out`; сценарий целиком — `--direction out -d all` |
| Импорты файла, кто его импортирует | `cs deps <файл>` (`type-only` — только `import type`) |
| Граф модулей, связность | `cs deps <каталог> --level N` — рёбра модулей, Ca / Ce / нестабильность; `--external`. Модули-файлы `core/*.ts` в `--level` входят в `core`; границы модулей — `packages/cli/test/unit/meta/architecture.json` (ADR-0030) |
| Циклы импортов | `cs deps --cycles --in <путь>`; без `import type` — `--runtime`; модулей — `cs deps <каталог> --level N --cycles` |
| Одноимённые определения | `cs dups --in <путь>` (`--min N`) — имена, у которых граф теряет вызовы из других файлов |
| Незнакомая область | `cs map` — один раз, дальше по названным узлам |

## Сценарии

| Ты… | Путь |
|---|---|
| Меняешь сигнатуру или поведение символа | `cs impact <символ>` → правки по списку → `callers -d 2`, если важна цепочка дальше |
| Не знаешь, где это | `cs ask "<поведение>" --source` → `skeleton` нужного файла → Read диапазона |
| Переносишь вызовы за порт | `cs impact <функция>` (все места) → правки по списку |
| Разбираешь падение теста | `cs ask "<симптом>" --source` → `impact` / `callers` подозреваемого |
| Пишешь тест на функцию | `cs skeleton <файл>` + `cs impact <функция>` |
| Оцениваешь архитектуру | `cs map` → `cs deps <каталог> --level N` → `--cycles --runtime` → `cs dups` → срез `callers <вход> --direction out -d all --json` |
