# Аудит Graft — 2026-09-24

После принятия ([ADR-0028](../adr/WARRANT-ADR-0028-graft-adoption.md)); решения — [ADR-0029](../adr/WARRANT-ADR-0029-graft-audit-dev-hooks.md).
Четыре направления, каждое сверено с эталоном, а не с самооценкой агента. Graft 0.19.0, `main` `4a3c586`.

## 1. Содержимое графа против компилятора TypeScript

Эталон — type checker TypeScript по всем 207 файлам (`allowJs` для `scripts/**`); ребро — пара узел-вызывающий →
узел-вызываемый. Повторяемо: `node scripts/dev/graph-audit.js` (ADR-0029 п. 4).

| | src | test | scripts | всего |
|---|---|---|---|---|
| Полнота узлов (функции, методы, классы, интерфейсы, типы) | 97,9 % | 96,9 % | 77/78 | 97,6 % |
| Точность рёбер вызовов | 99,4 % | 99,3 % | 102/103 | 99,4 % |
| Полнота рёбер вызовов (прямые) | 98,1 % | 77,2 % | 102/104 | 87,8 % |
| Полнота с вызовами через интерфейс / порт | 90,8 % | 72,6 % | 102/104 | 82,2 % |
| Импорты файл → файл, точность / полнота | 100 / 99,2 % | 100 % | 100 % | 100 / 99,6 % |

Классы ошибок по влиянию на ответ `callers`:

1. **Вызов через порт — 0 из 284.** Graft разрешает вызов по имени (tree-sitter), вызов метода — только у `this` или
   типа, известного в файле. `ctx.git.head()`, `ctx.checks.run()`, `ctx.openspec.version()` не видны: `cs callers
   CheckRunner.run` → «no indexed callers» без предупреждения при вызове `check.ts:225`.
2. **Имя определено в нескольких файлах — вызов из другого файла 4 из 141.** `readRecords` (второе определение —
   `scripts/dev/graft-metrics.js`), `classify`, `resolve`, `runCli`: 0 вызывающих вместо 2–4. Граф здесь пишет
   «may undercount».
3. **Метод у нетипизированного или цепочечного получателя:** `ident.m()` — 141 из 347, `a.b.m()` / `f().m()` — 12 из
   230 (построитель `project().withChange().synced()` в тестах).
4. **Ложные рёбра — 11, один класс:** локальная переменная или параметр с именем функции (`forward` в `runCommand`,
   `policy`, `call`, `setup`); 5 из них делают код src «вызывающим» тестовый helper.
5. **Строка под вызывающим** — первое вхождение имени в теле, а не вызов: в 31 % это объявление, импорт, комментарий
   или строка.

Свежесть: каждый запрос обновляет граф по size / mtime / sha256 файла, межфайловые рёбра пересчитываются целиком —
устаревших рёбер нет. Два агента в одном worktree: у graft свой замок, но сборку при отсутствии индекса `cs.js`
запускал без замка.

## 3. Поле — как агенты `[A]` пользовались графом

Транскрипты `test-levels` g1, g3, g5 и бенчмарка `[A]`; ответы `cs` сверены с `git grep` на тех же коммитах.

- **Тихих промахов в коммитах нет:** 4 изменения сигнатур и удаления (`checkPlacement`, `fake-openspec.ts`, e2e) —
  `callers` до правки, все места учтены.
- `cs grep` = `git grep` в 27 из 27 проверенных ответов; устаревших `file:line` нет.
- **Неполные ответы:** `callers runCli` (g1) — 0 вызывающих из 171 и молча потерянный вызов из
  `scripts/golden-update.js` (агент ушёл в `cs grep`, в отчёт не попало); `cs grep "a\|b"` (g5) — пусто при 7
  существующих функциях (JS-regex: `\|` — литерал); `skeleton` не показывает константы модуля и тела скриптов → чтение
  файла целиком.
- **Правило 2 обходилось:** 55 из 119 чтений кода — целые файлы через `offset=1, limit=N` (в g5 — 420 КБ, в 3,4 раза
  больше всего вывода `cs`); детектор насчитал 0. Навык сам допускал «у короткого диапазон `1..N`». Части группы g5
  перечитывали те же файлы (`project-builder.ts` — 4 раза).
- **Самоотчёты неполны:** промах `runCli` и чтения целиком в отчёты не попали.

## 5. Архитектурный аудит — что мешало инструменту

Отдельная сессия (навык `architecture-audit`) оценивала связность модулей через `cs`. Работало: срез сценария
`callers --direction out -d all` (~1 с), раздельные одноимённые определения в `callers`, хабы в `map`, ответственности
в `skeleton`. Мешало: рёбер импорта в выводе нет — у каждого файла «0 in-edges», хотя в индексе 715 рёбер `imports`
файл → файл (§1); граф модулей и циклы восстанавливались своим парсером текста `cs grep` (~25 с, `grep` режет
выдачу на 300 совпадениях, заголовки групп двух форматов — первая версия парсера молча приписала совпадения не тем
файлам); `--json` обёртка не пропускала; `ask` — лексический («где определены переходы lifecycle» — мимо).
Неверных ответов `cs` не было. Исправлено ADR-0029 п. 2: `cs deps` (файл, модули, циклы), `cs dups`, `--json`.
