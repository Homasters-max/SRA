# Черновики для grilling

Идеи, которые ещё не решены. Черновик — вход grilling'а, а не норма: ссылаться на него из ADR, specs, навыков и `CLAUDE.md` нельзя.

- **Папка на тему:** `docs/drafts/<YYYY-MM-DD>-<тема>/`. Дата — день, когда появились идеи. `README.md` папки — индекс: что уже решено (не гриллить), порядок grilling, сквозные вопросы, проверенные факты.
- **Файл на ветку решений:** `NN-<тема>.md`. Разделы по порядку: **Проблема** (факты с источником и датой), **Идея**, **Вопросы для grilling** (нумерованные, у каждого — предварительная рекомендация), **Вне объёма**. Факты проверены на дату папки. Перед grilling проверить их заново.
- **Жизненный цикл:** черновик → grilling → ADR или Change → папка удаляется тем же PR, где записано решение (история остаётся в git). Не решённое остаётся в папке. Отложенное с триггером становится строкой в `docs/backlog.md`.
- **Запуск:** grilling папки начинается с файла передачи потока `docs/handoff/<поток>.md` (ADR-0032 п. 3).
