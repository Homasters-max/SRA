> Уточнено [ADR-0027](WARRANT-ADR-0027-graft-tuning.md): алгоритм поиска — не навык в `.claude/skills`, а текст [docs/process/code-search.md](../process/code-search.md) в промпте `[A]`; зонд проверяет и индекс памяти; основной замер — парный бенчмарк, метрика — прочитанные при исследовании байты, порог — отношение `[A]/[B]` ≤ 0,8 при recall не ниже.

## Context

Разработку WARRANT ведёт сессия-координатор, каждую группу задач `tasks.md` выполняет субагент Opus ([NEXT-SESSION](../archive/2026-09-24-next-session.md)). Каждый субагент заново исследует `packages/cli/src` (~23 тыс. строк TS с тестами): в транскриптах phase-3b на группу 36–98 shell-вызовов `cat` / `sed -n` / `grep` при 50–120 tool calls и 5–22 млн токенов (с кэшем). Это цена, которая платится заново в каждой группе, и риск пропустить затронутый код.

[Graft](https://github.com/trailhq/Graft) (npm `@nanonets/graft`, MIT) — локальный граф кода на tree-sitter для coding-агентов: `graft ask` (узлы по задаче), `callers` (кто вызывает символ), `skeleton` (API файла), `map`; граф обновляется по hash при каждом запросе, без LLM. Проверено 2026-09-24 на Windows 11 (Node 22, VS Build Tools): 0.19.0 ставится (нужен короткий путь — MAX_PATH, `npm i -g` годится), граф SRA — 4,5 с, 1033 узла, 3181 ребро; `callers evaluateGates` находит все 7 вызывающих мест.

Против полного внедрения:

- `graft init` пишет хуки в `.claude/settings.json` проекта и по умолчанию в `~/.claude/settings.json`, `~/.claude.json`, а также `.mcp.json`, `.gitignore`, `.ignore`. `settings.json` принадлежит будущему `warrant sync` ([03 §6](../03-architecture.md)); в SEF конфиги движков сверяются с эталоном побайтно, Beads отвергнут ровно за `bd init`, переписывающий конфиги агента (`integrations/2026-09-17-sef-platform-design.md`).
- Навык Graft требует использовать его «For ANY task», хук UserPromptSubmit подмешивает контекст в каждый ход, вывод CLI содержит инструкцию агенту сообщать пользователю «🌱 graft saved ~N tokens» — это конкурирует с `/opsx:*` и `/group-done`, а оценка «saved» считается против чтения файлов целиком и завышена.
- Markdown (ADR, design.md, specs) не индексируется — больше половины работы в репозитории Graft не касается.
- Pre-1.0: создан 2026-07-03, 31 версия за 2 месяца, breaking changes в 0.6 / 0.7 / 0.9 / 0.17; фокус смещается к SaaS Trail Brain, который выгружает `docs/adr`, историю PR и CODEOWNERS на trailhq.com и пишет «правила дома» в `CLAUDE.md` / `AGENTS.md` — второй источник решений рядом с ADR (INV-06).
- `graft build` без переменных окружения правит `.gitignore` и создаёт `.ignore` — рабочее дерево грязное.

SEF R1 (готовое вместо своего) — за; P9 / R2 (инструмент только под доказанную проблему) — против внедрения без замера.

## Decision

1. **Эксперимент, не внедрение.** Graft — инструмент разработки самого WARRANT, не часть продукта. Решение о постоянном использовании — отдельным ADR по итогам (п. 4). Продуктовая интеграция (сигнал blast radius для `classify`, контекст исполнителей SEF) — later, [13 §3](../13-roadmap.md).
2. **Только CLI через обёртку, ничего в конфигах агента.** Субагент обращается к graft только через `scripts/dev/cs.js`: подкоманды `ask`, `grep`, `skeleton`, `callers`, `map`, `version`; без `--deep`, `--lsp`, `--no-refresh`, `--dir`; версия ровно 0.19.0; индекс `graft/` обязан быть исключён из git (иначе код 2 / 3). Обёртка ставит переменные гигиены и телеметрии, строит индекс, вырезает строки «tokens saved» с инструкцией агенту и переписывает подсказки `graft <sub>` в `cs <sub>`. `graft init`, `upgrade`, `mcp`, `brain`, хуки, MCP, statusline, навык `.claude/skills/graft`, graphify — не используются.
3. **Установка и гигиена.** `npm i -g @nanonets/graft@0.19.0`; переменные пользователя `GRAFT_NO_GITIGNORE=1`, `GRAFT_NO_IGNORE=1`, `DO_NOT_TRACK=1`; `graft/`, `.graft/` — в `.git/info/exclude` (общий для всех worktree).
4. **Алгоритм поиска — навык `code-search`.** `.claude/skills/code-search/SKILL.md` (по образцу официального SKILL.md Graft, без «For ANY task» и без отчёта об экономии): код ищется только через `cs`, читается только диапазонами после `skeleton`, перед сменой сигнатуры — `callers -d 2`, перед многофайловой правкой — `-d all`; правила 1–6 обязательны. `disable-model-invocation: true` — навык получает только субагент, в чей промпт координатор вставил ссылку на него.
5. **Слепой замер.** Группы Change чередуются: нечётная — `[A]` (навык `code-search`), чётная — `[B]` (контроль); метка — в конце `description` вызова субагента, записываются все группы. Субагент не знает об эксперименте: общий блок промпта и разделы отчёта («Поиск по коду», «Проверки») одинаковы у `[A]` и `[B]`, `[A]` отличается одной строкой-ссылкой на навык; `CLAUDE.md` о Graft не говорит; команды координатора — нейтральные `/group-stats`, `/stats-report` с `disable-model-invocation`; перед первой группой — субагент-зонд проверяет, что ничего из этого ему не видно ([coordinator.md](../../.claude/skills/change-coordinate/SKILL.md) §1). Порядок раздачи — [docs/process/coordinator.md](../../.claude/skills/change-coordinate/SKILL.md), протокол — [docs/process/graft.md](../process/graft.md).
6. **Метрики и порог.** Из транскрипта субагента (`scripts/dev/graft-metrics.js`): токены (вход, кэш, выход, пик контекста), tool calls, исследующие вызовы, вызовы `cs` / `graft`, время, отступления от правил навыка; карточка координатора — красные прогоны `/group-done`, помог ли поиск, ввёл ли в ошибку. Записи — `<git-common-dir>/graft-lab/runs/`, вне git; фон — phase-3b g1–g5. Группа `[A]` с > 3 отступлениями — `compliant: false`, в вердикт не идёт. **Accept**, если в каждой метке ≥ 2 засчитанных групп, медиана токенов **или** tool calls `[A]` ниже `[B]` на ≥ 20 %, красных прогонов у `[A]` не больше, ни одного случая «`cs` ввёл в ошибку», ни одного вызова graft в `[B]`. Иначе — **reject**; мало групп — **insufficient** (продлить на фазу 4).
7. **Остановка сразу**, без добора групп: `cs` вернул код 3 или дерево грязное из-за graft; неверный ответ привёл к ошибке; установка сломалась; нужен upgrade. Откат — [graft.md](../process/graft.md) §7.
8. **Отчёт.** `/stats-report` — `docs/process/graft-report.md` (сводка, дельты, карточки, вердикт) и черновик ADR с итогом; коммит — отдельной веткой `process/*`, не в ветке Change (иначе `scope-valid`).

## Consequences

- Пропуск записи ловит `graft-metrics report`: группа закрыта в `tasks.md`, записи нет → `missing`, код 1; запись без метки `[A]` / `[B]` не пишется. `/group-done` не меняется — его выполняет субагент, об эксперименте он не знает.
- Нарушения п. 2 ловятся механически: обёртка отказывает (код 2 / 3); `graft` в группе `[B]` — код 1 `graft-metrics run`; отступления `[A]` считаются; грязное дерево — `git status --short` в `/group-done`.
- `scripts/dev/` не входит в пакет — `package-contents.test.ts`; версия CLI не меняется (R-14: скрипты разработки не поставляются).
- Корневой `CLAUDE.md` появляется впервые: только ссылки (NEXT-SESSION, процедуры, документ координатора), правил в нём нет — как в `.claude/` по P-1. Он загружается и в субагентов, поэтому о Graft не говорит.
- Остаточный риск слепоты: этот ADR, `docs/process/**` и строка индекса ADR доступны агенту, если он сам туда пойдёт; координатор их субагенту не называет. Видимость `disable-model-invocation` для субагентов и `description` вызова документацией Claude Code не описана — поэтому зонд и нейтральные метки.

## Alternatives

- **Внедрить по умолчанию (`graft init`)** — отвергнуто: запись в глобальные и проектные конфиги агента, хуки на каждый ход, конфликт с владением `settings.json` и эталоном SEF.
- **Не внедрять** — отвергнуто: проблема повторного исследования кода видна в транскриптах, проверка дешёвая и откатывается одной командой.
- **MCP вместо CLI** — отвергнуто: нужен закоммиченный `.mcp.json`, регистрация на каждый путь worktree или глобальная; вызовы CLI видны в транскрипте как команды и считаются аудитом.
- **Сказать субагенту, что идёт эксперимент** — отвергнуто: агент, знающий о замере, ведёт себя иначе (демонстративно использует или избегает инструмент), сравнение перестаёт быть чистым.
- **Шаг в `/group-done`** — отвергнуто: `/group-done` выполняет субагент, шаг раскрыл бы эксперимент; пропуск ловит `report` (`missing`).
- **Двойной прогон каждой группы (`[A]` и `[B]`)** — отвергнуто: вдвое дороже; чередование плюс фон phase-3b достаточно для порога 20 %.
- **graphify** — не для кода: пересобирает граф целиком, `callers` нет; два источника контекста хуже одного.
- **Trail Brain** — отвергнуто: ADR и история PR уходят во внешний SaaS, «правила» дублируют ADR.
