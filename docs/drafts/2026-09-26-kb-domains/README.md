# Домены знаний для агентов — индекс черновиков (2026-09-26)

Поиск по документации для агентов WARRANT: документы режутся на units (одна норма — один unit со ссылками на
документ, код, тесты), units группируются по доменам, агент ищет в своём домене. Пилот — домены `lifecycle` и
`kernel`, навык `kb-search` (`~/.claude/skills/kb-search`, вне репозитория), данные — `.kb-search/` основного checkout
(в `.gitignore`). Черновики — вход grilling'а, не норма.

## Уже решено (не гриллить)

- **Jev остаётся.** На вопросах без слов документов (ловушки) BM25 слеп, Jev находит: MRR раздела в домене BM25 0,02 /
  0,45, Jev 0,90 / 1,00 (контроль 2026-09-26c, lifecycle / kernel).
- **Поиск в домене лучше поиска по документам целиком** — принято по заранее записанному критерию (ΔMRR ≥ 0,05, нижняя
  граница 95% > 0): lifecycle +0,34 [0,16; 0,54], kernel +0,66 [0,46; 0,82]. Раздел-ответ в топ-3 — 100 % в обоих.
- **«BM25 первым, Jev при сомнении» — отклонено данными:** уверенный BM25 (top1/top2 ≥ 1,2) ответил бы сам на 11 из
  38 вопросов и ошибся бы на 6; самый «уверенный» — ловушка C-L17, неверно.
- **Словарь домена — в `state` запроса Jev**, не в каждый вопрос: токены линейны по числу вопросов (~415 на unit),
  `state` — один раз; −42 % цены (замер `jev-1.13.0`).
- **Модель сущностей строится на контракте LATTICE** (maintainer): LATTICE будет классифицировать все сущности;
  локальный слой пишется в его форме, чтобы переход был заменой источника (02-entity-model).
- **Кэш по хэшу нормализованного вопроса сохраняется как самостоятельный модуль** (maintainer): механизм для встраивания
  в другие места SEF и в другие проекты, независимо от доли повторов.
- **Архитектура — модульная, гибкая и простая сразу** (maintainer): концепции перетекут в другие проекты (08).
- **Вопрос с ID нормы** (`REQ-…`, `SCN-…`, `ADR-…`, `I-`, `BL-`, `A-`) — прямой поиск по якорям, без Jev.

## Сквозные вопросы

- Домен — граница знания и работы, не модуля кода (код слоистый, ADR-0030; transition / verify / gate / archive
  делят одну модель — аудит 2026-09-26, 19–20 общих модулей).
- Всё машинное — JSON (ADR-0006); второй формат (SQL, YAML) не вводится.
- Навык `kb-search` вне репозитория: его правки не проходят PR и тесты WARRANT.
