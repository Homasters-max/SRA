# skills-git-hygiene

## Цель

Провести grilling черновиков [docs/drafts/2026-09-24-skills-git-hygiene/](../drafts/2026-09-24-skills-git-hygiene/README.md)
и записать решения в ADR. Темы: git как системный процесс, процедуры PR жизненного цикла Change, структура и гигиена
репозитория, ревью и CI, что взять из agency-agents.

## Готовый запрос

```text
Grilling по черновикам docs/drafts/2026-09-24-skills-git-hygiene/ (навык grilling). Начни с README.md папки: что
уже решено ADR-0032 — не гриллить; сквозные вопросы X1–X3 — первым раундом; дальше файлы в порядке таблицы README
(01 → 02 → 03 → 04 → 05), вопросы каждого файла — раундом, с учётом зависимостей. Факты из «Проблема» и «Факты,
проверенные 2026-09-24» перепроверь до раунда (ветки, настройки GitHub, структура). После последнего раунда — сводка
решений, затем ADR (одно или несколько — по вопросу X1 и объёму) на отдельной ветке; решённые файлы черновиков удалить
тем же PR, отложенное — строками в docs/backlog.md; этот файл передачи — удалить или заменить файлом потока реализации.
```

## Открытые вопросы

- Вести ли grilling до реализации ADR-0032 или после. Черновики опираются на его стандарт навыков и `backlog.md`.
- Настройки GitHub (squash и rebase, 01 G4) меняет только maintainer.

## Не забыть

- Реализация ADR-0032 идёт параллельно (ветка `process/dev-context`): имена `backlog.md`, `handoff/`, `brief.js` в
  черновиках — по тексту ADR. Перед grilling сверить с тем, что получилось.
- В ADR-0011 (Consequences) предполагается branch protection, а у приватного репозитория на бесплатном плане её нет.
