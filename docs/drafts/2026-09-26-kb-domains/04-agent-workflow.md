# Работа агентов с доменами: координатор, кодер, ревьюер

## Проблема

- Транскрипты 22–26.09 (202): кодеры — 68 запусков (~13/день), ~82 вызова инструментов, из них ~20 — код (`cs`, чтение `.ts`), ~7 — артефакты своего Change, ~3 — нормы; основная сессия — 42 (~8/день), ~14 обращений к нормам; ревьюер реализации — 3–4, ~5 к нормам и 13 `cs`; ревьюер spec — 7–9, ~0 (Context Pack).
- Оценка: ~80 поисков в день (пик ~170), ~$0,15–0,35 в день — цена и задержка не ограничивают; ограничивают точность и контекст агента. Оценка «поиск заменяет 2–3 обращения» — не замер.
- Каждый кодер ищет нормы сам и по-своему; одинаковые вопросы повторяются в группах одного Change.

## Идея

- **Координатор** (`change-coordinate`, ветка `process/kb-domains`, коммит c3bbf7f): шаг «Пакет норм» — 3–5 вопросов по группе в домене Change + `--by-code` по меняемым символам → units в промпт кодера; `conflict` — вопрос maintainer'у до раздачи.
- **Кодер:** читает пакет (строки `refs.docs`, код `refs.code` через `cs`), новые вопросы — `--domain`, до 3 за группу; нет нормы или низкая уверенность — в отчёт «Нормы», не додумывать.
- **Ревьюер реализации:** diff → символы → `--by-code` → нормы и `refs.tests` → сверка.
- **Код** — только через graft / `cs` (живой граф); домен хранит якорь символа.
- **design.md Change** объявляет домен (и ключевые units?) — один комплект для кодера и ревьюера.

## Вопросы для grilling

1. Домен Change — где объявлять: design.md, proposal или record? Рекомендация: design.md (строка «Домен»), проверка формы — `validate`? или только навык.
2. Бюджет кодера 3 поиска на группу — достаточно? Рекомендация: да; счётчик — из `usage.jsonl` по сессии.
3. Пакет норм — только в промпте или ещё файлом в worktree (читать повторно, сверять в ревью)? Рекомендация: в промпте; копия — в отчёт группы.
4. `review-impl`: сделать `--by-code` обязательным шагом ревьюера? Рекомендация: да, после доменов в репозитории.
5. Метрика пользы: «Нормы» в отчёте → `--used` → карточка `group-stats`? Рекомендация: добавить поле `norms_helped`, `norms_missing` в карточку наблюдения.
