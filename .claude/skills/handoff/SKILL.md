# Передача потока

Перезаписывает `docs/handoff/<поток>.md` целиком по форме [ADR-0032](../../../docs/adr/WARRANT-ADR-0032-dev-context.md) п. 3. Состояние (ветки, теги, версии, задачи) не пишется — его вычисляет `scripts/dev/brief.js`; решения — в ADR или design.md, долг — в `docs/backlog.md`.

## Вход

- `$ARGUMENTS` — поток (`phase-4`, `git-flow`, …) и необязательная сводка сессии. Поток — линия работы с одной целью; файл едет в ветке своего потока.

## Шаги

1. Факты — из репозитория, не из памяти:
   ```bash
   node scripts/dev/brief.js
   git log --oneline -10
   ```
2. Разнести сделанное по местам (п. 1): решение по Change — `decision` (I-N); по процессу или норме — ADR; долг найден или закрыт — строка `docs/backlog.md` добавлена или **удалена**; правило получило проверку — строка `docs/process/rules.md`.
3. Следующий шаг — новая фаза roadmap (grilling нарезки или spec-PR): готовый запрос начинается с навыка `architecture-audit` (`--against` последний снимок `docs/process/audits/*.json`). Снимок старше последнего тега `v*` — пометить «снимок устарел, аудит обязателен»:
   ```bash
   git log -1 --format=%cs "$(git tag --list 'v*' --sort=-v:refname | head -1)"
   ls docs/process/audits/
   ```
   Открытые `A-N` из `backlog.md` — в запрос как вход grilling'а.
4. Перезаписать `docs/handoff/<поток>.md` — строго так:
   ```markdown
   # <поток>

   ## Цель
   1–3 строки.

   ## Готовый запрос
   Блок ```text``` — что прочитать, ветка/worktree, что сделать, что спросить у maintainer'а.

   ## Открытые вопросы
   К maintainer'у; нет — «нет».

   ## Не забыть
   До 5 пунктов — только то, что нельзя вычислить.
   ```
   Не больше 60 строк; истории, таблиц решений и состояния нет. Поток закончен — удалить файл или заменить файлом следующего потока.
5. Проверить:
   ```bash
   npx vitest run --config packages/cli/vitest.config.ts --project unit test/unit/meta/dev-context.test.ts
   git diff --stat docs/
   ```

## Стоп

- Поток не ясен (ветка не называет его, сводки нет) — спросить.
- Факт нужен, но не вычисляется и его нет в сессии — не придумывать: вопрос в «Открытые вопросы».
- Пункт «Не забыть» шестой — перенести лишнее в `backlog.md` или ADR, а не раздувать файл.

## Отчёт

Путь файла, `git diff --stat`, результат `dev-context.test.ts`. Не коммитить без подтверждения пользователя (или в рамках `group-done`).
