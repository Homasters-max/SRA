## 1. Вердикт

**Бенчмарк (основной замер, ADR-0027 п. 4): `accept`.** Медиана отношения прочитанных при исследовании байт `[A] / [B]` — **0,54** (порог ≤ 0,8); recall и precision — **1,0 у обеих меток** на всех 8 вопросах; `cs` в `[B]` — ни разу; отступлений от алгоритма в `[A]` — 0.

**Поле (справочно): `reject`** по одному формальному условию — красный прогон в g5 `[A]` (таймаут теста под нагрузкой, к поиску не относится; устранён группой 6). По метрике поле согласуется с бенчмарком: медиана `explore_bytes` `[A]` ниже `[B]` на 51 %, до первой правки — на 41 %.

- **Где граф выигрывает сильнее всего** — цепочки вызовов и импорты (q4, q6): один `callers` вместо серии grep по каждому звену. q4 `[B]` — 8 вызовов против 3.
- **Где не выигрывает** — q2: `[A]` сделал `callers` и затем проверочный `cs grep` по тем же именам (правило 4 это допускает для полноты), вывод `grep` графа длиннее, чем у Grep с `output_mode: content`. q8 — паритет.
- **Ловушка графа (q8).** `cs callers evaluateGates -d all` добавляет ложную цепочку `runCommand → runOne → executeChecks → runCheck`: в `runCommand` есть локальная переменная `forward`, граф связывает её с функцией `forward` из `transition.ts` по имени. Агент `[A]` проверил рёбра через `cs grep` и исключил их — правило 3 («каждое место из ответа — учесть или отметить, почему не затронуто») сработало. Без проверки это была бы ошибка.

## 4. Оговорки

- **Потолок на бенчмарке.** Все 16 ответов точны: вопросы оказались по силам обеим меткам, recall не различает их. Бенчмарк показывает цену поиска при равном качестве, но не проверяет, находит ли граф то, что grep пропускает.
- **Малые абсолютные объёмы.** На вопрос читается 1–15 КБ; основная часть токенов субагента — постоянный контекст (~45 тыс. токенов на запрос). Поэтому токены падают на 22 %, а прочитанное — на 33–46 %. В поле объёмы исследования на порядок больше (100–300 КБ на группу) — там выигрыш весомее.
- **Один прогон на пару**, без повторов: разброс не оценён; q2 показывает, что отдельная пара может идти против.
- **Поле смешано** по объёму групп (105–9 911 строк); g5 — пять субагентов суммой. Поле — только согласованность направления.
- **Слепота поля нарушена** (`blind-leak`, индекс памяти — ADR-0027); поведение `[B]` не изменилось (`cs` — 0). Бенчмарк прошёл уже без утечки.
- **Graft pre-1.0**, ложные рёбра по совпадению имён (q8) — риск остаётся, держится правилом 3.
